Pełny poradnik:
Jeśli masz konto na Discloud Zaloguj się, a jeśli nie, to stwórz je za darmo. Strona discloud.com
Pobierz discloud.zip
6. Podmień role, kanały, (ID) itp. (najlepiej zapytaj się ChatGPT lub DeepSeek, jeśli nie wiesz, co zrobić).
Kliknij "Upload", aby dodać aplikację Discloud
Wrzuć plik .zip, którego pobrał*ś.
W zakładce "Applications, kliknij nazwę aplikacji.
Przejdź na Variables.
Dodaj variable (zmienną).
Znajdź KEY i wpisz DISCORD_TOKEN i VALUE=TWÓJ_TOKEN_BOTA_NA_DISCORDZIE
Kliknij "Overview".
Kliknij Rebuild, odczekaj i kliknij "Start".
